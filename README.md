# ai-shell 🤖 v0.7.0

**AI Shell** — умная CLI-утилита, которая не переизобретает LLM-клиент.

Вместо этого `ai` использует уже установленный **Hermes Agent** с его моделями, API-ключами, Gateway, Telegram и всеми инструментами.

## Преимущества

| | sgpt | aichat | **ai (наш)** |
|---|---|---|---|
| **Агентные возможности** | ❌ | ❌ | ✅ (весь Hermes) |
| **Инструменты** (web, файлы, shell) | ❌ | ❌ | ✅ |
| **Telegram-интеграция** | ❌ | ❌ | ✅ |
| **Локальные модели** | через бэкенд | через бэкенд | ✅ (через Ollama) |
| **Shell-команды** | ✅ | ✅ | ✅ |
| **Explain ошибок** | ✅ | ✅ | ✅ **+ авто-explain** |
| **Pipe-режим** | ✅ | ✅ | ✅ |

## Установка

```bash
# Симлинк в ~/.local/bin/
ln -sf "$(pwd)/bin/ai" ~/.local/bin/ai
```

**Зависимость:** Hermes Agent (уже установлен).

## Использование

### Прямой вопрос
```bash
ai "как найти все jar файлы в системе"
```

### Shell-команда
```bash
ai -s "заархивировать логи за вчера в tar.gz"
ai -s "найти процессы java, сортируя по памяти"
```

### Объяснение ошибок
```bash
# Только ошибка (авто-explain)
# make это вызываемая команда которая выдает ошибку
# 2>&1 | это перенаправление только сообщение об ошибках в пайп
make 2>&1 | ai

# Ошибка + запрос
make 2>&1 | ai -e "предложи фикс и напиши Makefile"

# Из файла
ai -e < compile_errors.log
```

### 🆕 Авто-explain
Любой вывод из пайпа без запроса автоматически анализируется — ищет ошибку, причину и решение:

```bash
make 2>&1 | ai
# → "Ошибка: нет цели build. Проверь Makefile..."

ssh server 2>&1 | ai
# → "Connection refused. Возможно, SSH не запущен..."

kubectl apply -f deploy.yaml 2>&1 | ai
# → "Ошибка валидации YAML. Строка 42: неверный отступ..."
```

### Pipe с контекстом + запрос
```bash
ps aux | ai "найди процессы java и отсортируй по памяти"
cat nginx.conf | ai "проверь конфиг на ошибки"
git diff | ai "напиши commit message"
```

### Генерация кода
```bash
ai --code "python-скрипт для бэкапа папки"
```

### Чат с контекстом (--chat)

Интерактивный диалог с сохранением истории — каждая сессия именованная и продолжается между запусками:

```bash
ai --chat                    # REPL, сессия "default"
ai --chat -n работа          # REPL с именованной сессией "работа"
ai --chat -n работа "вопрос" # одно сообщение в сессию (с контекстом!)
ai --chat -l                 # список сохранённых чатов
ai --chat -d работа          # удалить чат из реестра
```

Внутри REPL: `/help`, `/exit`, `/new [имя]`, `/sessions`, `/model <модель>`, `/clear`, `/send [target]`, `/delete`.

```bash
ai --chat -n план "набросай структуру бэкапа"   # создаёт сессию
# какие то команды
ai --chat -n план "теперь добавь ротацию"        # продолжает ту же (контекст!)
```

### Отправка в Telegram
```bash
ai "погода в Краснодаре" --send
ai "деплой прошёл успешно" --send telegram:-1003813611487:1
```

### Дополнительные опции
```bash
ai -m anthropic/claude-sonnet-4 "напиши haiku про Linux"   # смена модели
ai -p openrouter "вопрос"                                    # смена провайдера
ai -s -r "удалить все .tmp файлы"                           # shell + выполнить
ai -5 "кратко про HTTP"                                      # уровень детальности 5 (1..9)
ai -v 9 "развернутый ответ"                                  # то же через -v
ai -c "объясни этот код"                                     # скопировать ответ в буфер обмена
ai --fix-sessions                                            # починить названия старых CLI-сессий
```

## Архитектура

```
┌──────────┐   prompt     ┌──────────┐   response    ┌──────────┐
│  ai      │ ───────────▶ │  hermes  │ ────────────▶ │  stdout  │
│ (Python) │              │  -z (1)  │                │ (pipe)   │
└──────────┘              └──────────┘                └──────────┘
     │                         │                           │
     │ --send                  │ Telegram                  │
     ▼                         ▼                           ▼
┌──────────┐            ┌────────────┐              your terminal
│ Telegram │            │ hermes send │             / shell pipe
│ (home)   │            └────────────┘
└──────────┘
```

### Режимы

| Команда | Что делает |
|---------|------------|
| `make 2>&1 \| ai` | 🆕 **Авто-explain** — анализирует ошибку, ищет причину и решение |
| `ai "вопрос"` | Прямой вопрос, ответ текстом |
| `ai -s "задача"` | Генерирует одну shell-команду |
| `команда \| ai -e "запрос"` | 🆕 Объяснение ошибки + дополнительный запрос |
| `команда \| ai` | 🆕 Авто-explain (без -e) |
| `ai --code "задача"` | Генерирует код в markdown |
| `ai --send` | Отправка результата в Telegram |

## Команды

```
ai [опции] "запрос"

Режимы:
  -s, --shell          Сгенерировать shell-команду
  -e, --explain        Анализ ошибки/вывода из stdin (+ опц. запрос)
  --code               Сгенерировать код
  --chat               Чат: интерактивный диалог с контекстом (или сообщение в сессию)
  -n, --name NAME      Имя сессии чата (по умолчанию: default)
  -l, --list-chats     Список сохранённых чатов
  -d, --delete-chat N  Удалить чат из реестра

Опции:
  -v, --verbose 1-9    Уровень детальности (кратко..подробно). По умолчанию 5.
                       Также работает сокращение: ai -7 "вопрос"
  -m, --model MODEL    Модель (anthropic/claude-sonnet-4, ...)
  -p, --provider PROV  Провайдер (deepseek, openrouter, ...)
  -c, --copy           Скопировать ответ в буфер обмена (xclip или wl-copy)
  --send [TARGET]      Отправить результат в Telegram (без ANSI-кодов)
  -r, --run            В --shell режиме: выполнить команду
  --no-color           Отключить цветной вывод
  --fix-sessions       Исправить названия старых CLI-сессий в БД Hermes
  -V, --version        Показать версию
  -h, --help           Показать справку

Shell completion:
  source completions/ai.bash    # bash
  source completions/ai.zsh     # zsh
```

## Что нового в v0.7.0

- 🆕 **`--copy` / `-c`** — копировать ответ в буфер обмена (xclip X11 / wl-copy Wayland)
- 🆕 **Shell completion** — статические bash/zsh автодополнения (`completions/`)

## Что нового в v0.6.0

- 🆕 **`--chat`** — интерактивный REPL с именованными сессиями и сохранением контекста между запусками
- 🆕 **One-shot в сессию** — `ai --chat -n имя "вопрос"` продолжает тот же разговор
- 🆕 **Slash-команды** — `/help /exit /new /sessions /model /clear /send /delete`
- 🆕 **`-l` / `-d`** — список и удаление сохранённых чатов (`~/.config/ai-shell/chats.json`)
- 🆕 **Авто-восстановление** — если сессия удалена в Hermes, подскажет `/new`

## Что нового в v0.5.0

- 🆕 **Уровни детальности** — `ai -1..-9 "вопрос"` или `ai -v N`: от одной строки до исчерпывающего разбора
- 🆕 **Умные подсказки** — при опечатке в аргументе (`ai --expl` вместо `--explain`) подскажет похожие варианты
- 🆕 **`--fix-sessions`** — пакетно переименовывает старые CLI-сессии без названий
- 🆕 **Авто-названия сессий** — каждый запрос создаёт сессию `ai: <краткий заголовок>`, а не полный промпт
- 🆕 **`--send` без ANSI-мусора** — в Telegram уходит чистый текст, даже когда в терминале включены цвета
- 🆕 **Авто-explain** — `make 2>&1 | ai` сам понимает, что нужно анализировать ошибку
